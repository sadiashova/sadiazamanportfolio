# Sadiazamanportfolio

Technology Stack Requirements

Build the portfolio using Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, and Lucide React. Use reusable components, clean project structure, responsive layouts, and accessible UI.

Implement dedicated project detail routes for SilentAlert, Gatherly, and SubSphere. Keep project information in structured data so it can be updated easily. Optimize metadata, performance, and SEO.

Use my uploaded professional photograph as the profile image. Add subtle animations, elegant transitions, interactive project cards, and a mobile-friendly navbar.

The website must be fully functional and ready for free deployment on Vercel. Do not leave unfinished pages, fake buttons, broken links, or placeholder content where verified information is available.
